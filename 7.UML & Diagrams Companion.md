# 11. Notes

- TXT files are the Source of Truth.
- PostgreSQL stores metadata and semantic chunks.
- Semantic indexing runs using `IndexWorker` (a `SwingWorker`) to keep the UI responsive.
- If a save arrives while `IndexWorker` is already running, it is not queued — `pendingIndex` is set and the worker re-runs once on completion (Repeated Save Handling, see SDD §8.1).
- Semantic search falls back to keyword search when Ollama is unavailable.
- Search results are displayed as preview cards containing the most relevant chunk.
- These diagrams are simplified for an academic Object-Oriented Programming project while accurately representing the implemented architecture.
