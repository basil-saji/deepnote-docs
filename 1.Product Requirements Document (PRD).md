# Executive Summary

DeepNote is an offline AI-powered semantic note-taking application developed as the course project for Object-Oriented Programming using Java. Unlike traditional note-taking applications that rely only on keyword matching, DeepNote enables users to search notes by meaning using locally generated vector embeddings.

Notes are stored as standard TXT files to preserve portability and user ownership, while PostgreSQL with the pgvector extension stores only metadata and semantic index information required for efficient search. The application operates completely offline using locally hosted AI models, ensuring privacy and independence from cloud services.

# Problem Statement

Traditional note-taking applications depend mainly on keyword-based search. Users often remember concepts rather than exact words, making note retrieval inefficient.

DeepNote solves this problem by generating vector embeddings for note contents and performing semantic similarity search locally without requiring cloud services.

# Product Vision

To develop a lightweight, offline-first desktop application that combines the simplicity of plain text note-taking with the power of semantic search while preserving user privacy, portability and ownership of data.

# Engineering Principles

1. TXT files are the primary source of truth.

2. PostgreSQL stores only metadata and semantic index information.

3. Semantic search is the preferred retrieval mechanism.

4. Keyword search is automatically used when semantic search is unavailable.

5. Indexing must never block the user interface.

6. Re-index only when the note content changes.

7. External libraries should simplify implementation without tightly coupling the application to a specific framework.

8. Every design decision should remain easy to explain during project evaluation.
